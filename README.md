## About
Reconstruct What is a (over-engineered) JSON config library.

### Why make this mod?
I can't find a good config library, so I'm making my own.

## Features
- Easy configuration
  - Config value templates included:
    - Boolean
    - Double
    - Enum
    - Integer
    - List
    - Long
    - Map
    - ResourceLocation
    - String
    - UUID
    - many more to come!
- Configuration screen
